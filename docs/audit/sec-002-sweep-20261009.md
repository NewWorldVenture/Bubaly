## Checked and found safe (summary)

- **Redirects:**
  - Every sink was traced: middleware, auth callback/complete, login/signup/phone, PKCE initiation, step-up, native deep links, sign-out, every OAuth callback (X, Google Calendar, `sync/[provider]`, onboarding), blog unsubscribe, pay handle, purchase approval, AI `data.redirect`, billing `json.url`.
  - `safeInternalRedirect` was run against 25 payloads: the `/.//` and `%2e` fixes hold, and every accepted payload resolves on our origin.
- **Validation:**
  - Every route handler uses the bounded body readers.
  - Money actions derive the family from context and re-check `can_manage_family` in the RPC.
  - The checkout price is fixed server-side.
  - Admin actions call a super-admin guard.
  - Unauthenticated actions are schema-checked and rate-limited.
- **Secrets:**
  - An import graph from all 477 `'use client'` files found no non-`NEXT_PUBLIC_` env read.
  - The service-role factory imports `server-only`.
  - No hardcoded keys in the tree or git history.
  - Crons use constant-time `bearerMatches` and fail closed.
  - Stripe, Resend and Twilio verify signatures and fail closed.
  - `Referrer-Policy` keeps URL tokens same-origin.
- **Cross-site:**
  - No CORS headers.
  - Auth cookies are explicitly `SameSite=Lax`.
  - Server actions keep Next's Origin check.
  - Sign-out and billing check Origin.
  - Mutating GETs are token-bound.
  - `X-Frame-Options: DENY` and `frame-ancestors 'none'` everywhere except `/blog` (same-origin).
  - No `message` listeners.
  - The three `dangerouslySetInnerHTML` uses carry no user HTML.
  - Hardening only, not changed: CSP `script-src 'unsafe-inline'` with no nonce; `connect-src https://*.supabase.co`.
- **Uploads:**
  - avatars, marketplace-photos and feedback-attachments are folder-bound with image allowlists (no SVG) and size limits.
  - family-media writes go through `media_access` and message attachments through `message_guard`.
  - Object paths are built from ids or sanitized names.
  - The paperwork and email capture paths use magic-byte typing.
  - The media proxy pins DNS, allows only audio/video and sends `nosniff`.
  - Next's image optimizer keeps SVG off.
