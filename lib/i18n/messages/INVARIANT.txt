# Being listed here is a claim a reviewer can check. Without this file,
# "identical to English" is ambiguous — a decision someone made, or a
# translation nobody got to — and there is no way to tell which. Only two kinds
# of entry are legitimate:
#
#   1. Proper nouns, brands, and the placeholder names used in demo data.
#   2. Unit and separator fragments left behind when the extractor split a
#      sentence around a JSX expression, e.g. `{hours}h (` or `{n} min ·`.
#      These contain no translatable word. They are TECHNICAL DEBT, not
#      translations: the fix is to rewrite the source so the sentence stays
#      whole around a {placeholder}, then delete the line from here. Tracked in
#      docs/i18n.md under "Fragment debt".
#
# A string with an ordinary word in it does NOT belong here, however awkward the
# fragment — leaving real copy in English is the failure this whole effort is
# about.
